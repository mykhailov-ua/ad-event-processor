Ви зберігаєте мої кампанії?
Ні. Усе працює виключно на вашому сервері. У нас немає backend API, який збирає телеметрію, конфігурації кампаній чи логи відвідувачів.
Це як Keitaro в хмарі?
Ні — це локальне ПЗ, яке встановлюється прямо на ваш VPS. Поточні конфігурації можна імпортувати з Keitaro або Binom через JSON.
Що після пілота?
Оплачуєте USDT за відповідний тариф. Ми генеруємо і надсилаємо новий файл ліцензії. Завантажуєте його в існуюче розгортання — без перевстановлення.
Чи потрібно бути розробником?
Onboarding wizard проведе через першу кампанію. Admin console і API закривають щоденні операційні задачі.
Як почати?
Напишіть у Telegram, щоб отримати пілотну ліцензію. Запустіть однорядковий install script на сервері, активуйте ліцензію в браузері — і можна лити трафік.

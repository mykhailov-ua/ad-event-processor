Ваш сервер

Один інстал запускає маршрутизацію кліків, адмінку кампаній, облік бюджету та аналітику на залізі, яке контролюєте ви. Відвідувачі заходять на ваш домен; прийняті кліки логуються й проводяться на тій самій машині — не через наш датацентр.

Трафік на вхід

Ваша реклама веде кліки на URL трекера. Маршрутизація, landers і offer flows працюють локально.

Адмінка та білінг

Редагування кампаній, доступ команди, cost sync і payment hooks — у тому ж стеку, без окремої SaaS-консолі.

Дані залишаються локально

Конфіги кампаній, події відвідувачів і звіти — на вашому сервері. Ми не хостимо ваші воронки й не тягнемо телеметрію додому.

Фільтри до списання бюджету

Кожен клік проходить rule checks — гео, розклад, сигнали пристрою, consent і антифрод — до того, як рухається бюджет кампанії. Сміттєвий і підозрілий трафік можна відсіяти або показати decoy-воронку, поки витрати залишаються цілими.

Клоакінг вбудований. Без окремого рахунку за клоаку — модерація й фільтрація ботів у тому ж інсталі, що маршрутизація й звітність.

Важчі перевірки фроду та invalid-traffic scoring працюють як фонові задачі на ваших аналітичних даних і повертаються в live filtering — не per-click API-виклик до стороннього AI-сервісу.

Звіти та postbacks

Прийняті події потрапляють у ваше сховище звітів для дашбордів, експорту та dispute bundles. S2S postbacks відправляються на конверсіях; кожен крок логується — бачите, де зникли ліди між мережею, трекером і affiliate.

Cost sync підтягує витрати з налаштованих рекламних мереж за розкладом — звіряйте з ledger, не очікуйте real-time паритету з кожним UI мережі. Conversion API для Meta, Google і TikTok можуть працювати з того ж сервера — автоставки бачать реальні результати, а не лише напівсинхронізований browser pixel.

Файл ліцензійного ключа, без license server

Ваш тариф і feature flags живуть у файлі ліцензії, який вставляєте в Admin Settings після встановлення. Перевірка офлайн на вашому сервері — без phone-home на кожен клік, без vendor-акаунта, який блокує export або тримає ваші дані.

Після апгрейду надсилаємо новий файл; завантажуєте на місці без перевстановлення стеку. Втратили сервер? Напишіть у Telegram — можемо видати replacement key для задокументованих emergency.

Conceptual overview

How it works

BidShard is self-hosted software you install on your VPS or dedicated server. Your traffic stays on your metal — we ship the stack and a license file, not a shared cloud tenant.

On this page
  1. Your server
  2. Filters before budget spend
  3. Reports and postbacks
  4. License key file

Your server

One install runs click routing, campaign admin, budget tracking, and analytics on hardware you control. Visitors hit your domain; accepted clicks are logged and settled on the same box — not routed through our datacenter.

Traffic in

Your ads send clicks to your tracker URL. Routing, landers, and offer flows run locally.

Admin and billing

Campaign edits, team access, cost sync, and payment hooks live in the same stack — no separate SaaS console.

Data stays local

Campaign configs, visitor events, and reports sit on your server. We do not host your funnels or pull telemetry home.

Filters before budget spend

Every click passes rule checks — geo, schedule, device signals, consent, and antifraud — before your campaign budget moves. Junk and suspicious traffic can be turned away or shown a decoy funnel while your spend stays intact.

Cloaking built in. No separate cloaker bill — moderation and bot filtering run in the same install as routing and reporting.

Heavier fraud checks and invalid-traffic scoring run as background jobs on your analytics data, then feed back into live filtering — not a per-click API call to a third-party AI service.

Reports and postbacks

Accepted events land in your reporting store for dashboards, export, and dispute bundles. Server-to-server postbacks fire on conversions; each hop is logged so you can see where leads dropped between network, tracker, and affiliate.

Cost sync pulls spend from configured ad networks on a schedule — reconcile against your ledger, do not assume real-time parity with every network UI. Conversion APIs for Meta, Google, and TikTok can run from the same server so bidding sees real outcomes, not a half-synced pixel alone.

License key file, no license server

Your tier and feature flags live in a license file you paste into Admin Settings after install. Verification is offline on your server — no phone-home on every click, no vendor account that gates export or holds your data hostage.

When you upgrade, we send a new file; you load it in place without reinstalling the stack. Lost a server? Message us on Telegram — we can issue a replacement key for documented emergencies.

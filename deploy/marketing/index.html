Common Questions
Frequently Asked Questions
Why doesn't my tracker match the CPA network?
Usually status timing (hold vs confirmed), a broken subid parameter, or affiliate network shave. Pro tier logs every postback hop so you see exact drop points before arguing with screenshots.
Do I still need a cloaker?
Starter includes built-in cloaking — most teams drop their separate $300–$600/mo cloaker subscription immediately. Run the pilot on your GEOs and compare block rates.
Can I run the pilot parallel to Keitaro?
Yes — that is exactly what we recommend! Import your JSON config, duplicate postbacks on a test flow, keep Keitaro live until numbers match, then switch traffic.
Do you store my campaign funnels?
No! Everything runs exclusively on your server. We have zero backend endpoints collecting telemetry, funnel configs, or visitor logs.
How does BidShard compare to Keitaro or Binom?
Same self-hosted model on your VPS — your traffic never leaves your infrastructure. The key difference is one unified stack: routing, cloaking, IVT, cost sync, and CAPI without 4 separate subscriptions. Import JSON from Keitaro or Binom and run a parallel test.
What happens after the 10-day pilot?
Pay USDT for your matching tier. We issue a new license key file. Paste it in your web admin UI — no server reinstall required.
What if I lose a server or need an emergency migration?
Server crashed or provider banned? Message @bidshardsupportbot or @bidshard_manager on Telegram. We reissue your license key fast — works 100% offline.
Do I need to be a developer?
No full-time developer needed! Full web admin UI is included — campaigns, flows, reports, and Margin Guard in your browser. We help with 1-click install on Telegram.
How do I start the pilot?
DM us on Telegram for a pilot license. Run the 1-click install command, paste your key in the web admin, and launch a test campaign.
